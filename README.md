# EdmoBall

A private, family basketball desk for keeping track of Edmonton-area teams, tournaments, camps, tryouts, and leads.

## What the first version does

- Provides a watchlist for deadlines, tryouts, tournaments and general leads.
- Includes a starting directory of Edmonton-area clubs and community pathways.
- Keeps an official-source board with direct links.
- Lets a family member add a lead from a group chat, Instagram post, or conversation.

Family-added leads are saved in the browser on the device being used. They are deliberately not published to the repository, so a rumour or note does not become public by accident.

## Use it

Open `index.html` in any modern browser. No account, tracking, or database is required.

## Next useful improvement

The next version can use a shared database so additions appear for every invited family member, then add a moderated submission queue and notifications for deadlines.
